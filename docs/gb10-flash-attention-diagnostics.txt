Issue 2: the full-capacity layout guard
--------------------------------------
Source: work/flash-probe/export.log
The tensor input has dynamic sequence length valid_keys. At length 1024,
128 * valid_keys equals the original head stride, 131072.

torch.fx.experimental.symbolic_shapes.ConstraintViolationError: Constraints violated (valid_keys)! For more information, run with TORCH_LOGS="+dynamic".
  - Not all values of valid_keys = L['k'].size()[2] in the specified range valid_keys <= 1024 satisfy the generated guard (128*L['k'].size()[2]) != 131072.

Scope of the conclusion
-----------------------
These probes isolate a mutation interaction in the tested compiler build.
They do not establish which internal compiler pass introduced the narrower
minimum. The final implementation avoids that input contract and passes the
full-model shape/cache checks. Numerical acceptance is a separate limitation;
see ../benchmarks/gb10-flash-2026-10-24/REPORT.md.
